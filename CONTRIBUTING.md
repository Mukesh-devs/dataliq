# Contributing to BigView

Thanks for helping! A few rules keep the project healthy.

## Setup

See "Building from source" in the [README](README.md). Then:

```sh
pnpm install
pnpm tauri dev
```

## Before every commit

Run the full check script and make sure it passes:

```sh
./scripts/check.sh        # Linux / macOS
./scripts/check.ps1       # Windows
```

It runs `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test`,
`pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm tauri build --debug`.
Use `--quick` / `-Quick` to skip the bundle build while iterating.

## Conventions

- Commits use [Conventional Commits](https://www.conventionalcommits.org/),
  e.g. `feat(import): open csv.gz with instant preview`.
- Never delete or skip a test to make it pass.
- Never commit large test data, build output, secrets or `node_modules`.
  Large fixtures are generated by `pnpm fixtures` (`scripts/gen_fixtures/`) into the
  git-ignored `fixtures/generated/` folder.
- Keep Tauri command handlers in `src-tauri/src/commands/` thin; real logic
  lives in the engine/sources/view modules where it can be unit tested.
- Never build SQL by concatenating user text: quote identifiers and bind values.
- Design decisions that deviate from `BUILD_PLAN.md` go in `docs/DECISIONS.md`.
